# Dokumentace AuctionHouse projektu

## Přehled projektu
**AuctionHouse** je webová aplikace pro online aukce implementovaná v tech stacku:
- **Frontend:** Angular (standalone komponenty)
- **Backend:** ASP.NET Core
- **Databáze:** Vlastní souborová databáze (JSON)

---

## 🗂️ Struktura projektu


AuctionHouseProject-csvimportworking/ 
├── Database/ # Souborová databáze 
│  ├── config.yml # Konfigurace databáze

│  ├── AuctionItems/ # JSON soubory s předměty

## 🗃️ Databázový systém

### Architektura
- **Vlastní souborová databáze** založená na JSON souborech
- Každá "tabulka" je reprezentována složkou s JSON soubory
- **AuctionHouseDatabase** objekt spravuje všechny datasety
- Globální zámek pro thread-safety

### Konfigurace (config.yml)
```yaml
Database:
  Users:
    assets: "Users"           # Cesta k JSON souborům
    properties: [...]         # Popis struktury (informativní)
  Auctions:
    assets: "Auctions"
    properties: [...]
---
